# Capstone submission checklist

- [ ] Run migrations and start Django; save output as `django_server`.
- [ ] Capture required cURL output files while the local stack is running.
- [ ] Capture required UI and deployment screenshots after verifying each flow.
- [ ] Push this project to your own public repository.
- [ ] Set a real deployment URL in `deploymentURL`; do not submit a placeholder.

The included code improves local configuration and API handling, but screenshots, CI run evidence, credentials, and a live deployment must be produced in the submitter's own environment.
